# GeoCalc Studio 📐
**Curso:** Programación II  
**Catedrático:** Ing. Bilder Fuentes  
**Universidad Mariano Gálvez de Guatemala**

Aplicación de escritorio desarrollada en Java Swing y gestionada con Apache Maven para el cálculo de áreas y perímetros de figuras geométricas (Rectángulo, Cuadrado, Triángulo y Trapecio) enfocada en un despacho de arquitectura.


##  Tecnologías y Arquitectura
- **Lenguaje:** Java 21
- **Interfaz Gráfica:** Java Swing (GUI)
- **Gestor de Proyecto:** Apache Maven
- **Patrón / POO:** MVC, Abstracción, Herencia y Encapsulamiento.


## Instrucciones de Ejecución
1. Clona o descarga este repositorio.
2. Abre la carpeta del proyecto en **NetBeans IDE**.
3. Presiona la tecla **`F6`** para ejecutar la clase principal `GeoCalcStudio.java`.
